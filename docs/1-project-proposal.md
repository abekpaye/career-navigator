# 1 Project Proposal

The proposed intelligent web platform for personalized career navigation and professional development planning helps students and early-career users explore IT professions, compare their profiles with defined role requirements, and build a personal development roadmap. The diploma project will develop and evaluate this complete process, with particular attention to clear explanations and incomplete profile information.

## 1.2 Problem statement

Students preparing for an IT career need to connect their existing skills and projects with the requirements of a profession. A list of technologies in a vacancy does not explain which requirements their profile already covers, what information needs clarification, or which development steps should come first. These difficulties are particularly relevant when a user has little commercial experience or only a short CV.

The problem addressed by this project is the lack of a clear connection between a user’s profile, a selected IT profession and an actionable development plan. The proposed contribution is to connect these stages in one workflow and evaluate their usefulness. Employer requirements will be documented as selected role profiles rather than presented as universal standards.

## 1.3 Target users

The primary users are university students, recent graduates and junior specialists exploring an IT direction or preparing for an internship or first job. The system will support users with a CV and users who prefer to enter their details manually. Users may explore recommendations or choose a target profession independently. The initial evaluation will focus on students and early-career users in Kazakhstan.

## 1.4 Project aim

The aim is to develop and evaluate a web platform that converts a user-reviewed profile into explainable IT career recommendations and a personal development roadmap based on documented role requirements, skill prerequisites and the user’s available study time.

## 1.5 Project objectives

- Identify user needs. Analyse the interviews, literature and existing systems, then define functional and non-functional requirements with priorities and acceptance criteria.

- Prepare the career knowledge model. Define an initial catalogue of ten IT professions, map relevant skills to ESCO identifiers, and document role requirements, prerequisites and available Kazakhstan vacancy evidence.

- Build an editable profile. Support manual entry and CV extraction for skills, languages, projects and experience, with user review before analysis and clear handling of missing information.

- Develop explainable recommendations. Combine semantic skill mapping with explicit matching rules, rank professions, and show the requirements supporting each result. Compare the method with an exact or alias-based baseline.

- Create actionable roadmaps. Order development steps using prerequisites and include tasks, expected outputs, completion criteria, effort estimates and reviewed learning resources.

- Implement the integrated application. Connect a responsive web client with a backend API and persistent database, supporting English, Russian and Kazakh interfaces.

- Support continued use. Allow users to edit profiles, refresh recommendations, adjust weekly study time and track progress while preserving earlier plans when a new plan is created.

- Evaluate the result. Check extraction and matching quality, roadmap consistency and source support through labelled examples and expert review; assess usability and perceived usefulness through user tasks and feedback.

## 1.6 Project scope

The project will focus on career navigation and professional development planning for an initial catalogue of ten IT professions. The role requirements and supporting sources will be documented for this catalogue. Kazakhstan vacancy information will be considered where reliable data is available.

### In scope

- User accounts and persistent storage of profiles, development plans and progress.

- Manual profile entry and PDF or DOCX CV extraction, followed by user review and editing of skills, languages, projects and experience.

- An initial catalogue covering Junior Data Analyst, Frontend Developer, Backend Developer, Full Stack Developer, Data Engineer, QA Engineer, DevOps Engineer, Cybersecurity Analyst, Machine Learning Engineer and Mobile Developer.

- Up to ten ranked career recommendations, with explanations of matched requirements, known gaps and information not specified in the profile.

- Independent selection of a target profession and creation of a roadmap covering technical development, language practice, practical projects and career preparation.

- Roadmap steps with suggested actions, expected outputs, completion criteria, prerequisite relationships, effort estimates and reviewed learning resources.

- Progress tracking, adjustment of weekly study time, explicit recommendation updates and preservation of earlier plans when a new plan is created.

- A responsive web interface in English, Russian and Kazakh.

### Out of scope

- Career guidance for professional fields outside IT.

- Employer recruitment operations, including publishing vacancies, selecting candidates and making hiring decisions.

- Delivering educational courses, conducting formal qualification examinations or issuing professional certificates.

A match percentage will describe coverage of the documented role requirements. Roadmap completion will record the user’s progress. These indicators will not certify proficiency or guarantee employment. Effort estimates will guide scheduling rather than guarantee learning outcomes.

## 1.7 Expected outcomes

The main deliverable will be a working web application in which users can create and review a profile, receive explained IT career recommendations, choose a target profession, build a development roadmap and save their progress. The interface, backend and database will work together to support this complete user workflow.

Supporting deliverables will include the structured career and skill catalogue, documented matching and planning rules, a reviewed learning resource collection, an API specification and setup instructions. An evaluation report will present extraction and recommendation results, comparison with a simpler matching baseline, expert review of roadmaps and findings from user testing.

The intended practical outcome is that users can understand which role requirements their profiles cover, identify information to clarify or skills to develop, and choose a concrete next action.
